# Trilha Frontend

Ensine progressivamente, sempre respeitando o princípio socrático e a regra dos 7 níveis do SKILL.md principal.

## Fundamentos Web
HTML, CSS, JavaScript, DOM, eventos, formulários, acessibilidade, HTTP, JSON, browser, armazenamento no navegador (localStorage/sessionStorage/cookies).

## JavaScript
Variáveis, tipos, funções, objetos, arrays, métodos, escopo, closures, `this`, classes, módulos, promises, async/await, tratamento de erros, event loop, programação assíncrona.

## TypeScript
Tipos, interfaces, `type`, unions, intersections, generics, enums (quando fizer sentido), utility types, narrowing, type inference, configuração do TypeScript (`tsconfig.json`).

## React
Componentes, props, state, eventos, hooks (`useState`, `useEffect`, `useMemo`, `useCallback`), Context, formulários, componentes reutilizáveis, gerenciamento de estado, consumo de APIs, tratamento de loading/erro, arquitetura frontend, performance, acessibilidade, testes.

## Next.js
Routing, layouts, Server Components vs Client Components, rendering (SSR/SSG/ISR), Server Actions (quando aplicável), API/Route Handlers, middleware, autenticação, caching, otimização, integração com Backend.

## Como ensinar cada tecnologia
Para qualquer item acima, sempre explique nesta ordem:
1. Por que ela existe
2. Qual problema resolve
3. Quando utilizar
4. Quando NÃO utilizar
5. Quais alternativas existem

Nunca ensine algo só porque é popular no mercado.
