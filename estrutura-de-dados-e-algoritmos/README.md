# Estruturas de dados e algoritmos

Este material apresenta fundamentos de representação de dados, análise de
complexidade, estruturas de dados e algoritmos em JavaScript.

## Ordem de estudo recomendada

1. [Representação de dados](./fundamentos/representacao-de-dados.md)
2. [Complexidade de algoritmos](./complexidade/README.md)
3. [Estruturas de dados](./estruturas-de-dados/README.md)
4. [Algoritmos](./algoritmos/README.md)
5. [Exercícios](./exercicios/README.md)

Cada capítulo combina explicação, análise de complexidade e exemplos que podem
ser executados separadamente com Node.js.

## Estrutura

```text
estrutura-de-dados-e-algoritmos/
├── fundamentos/
├── complexidade/
├── estruturas-de-dados/
├── algoritmos/
├── exercicios/
└── assets/
```

## Como executar os exemplos

Na raiz do repositório, execute o arquivo desejado:

```bash
node estrutura-de-dados-e-algoritmos/algoritmos/busca-binaria.js
```

Os exemplos usam apenas recursos nativos do JavaScript e não exigem instalação
de dependências.
